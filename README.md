# 나홀로법에 (NaholoBeobe)

AI 기반 나홀로 소송 지원 플랫폼 — Figma 디자인을 기반으로 구현한 실제 동작 웹 서비스(프론트엔드 데모).

> 변호사 없이 진행하는 ‘나홀로 소송’을 위해 절차 안내 · 법률 문서 자동 작성 · 판례 분석 · 증빙/일정 관리를 한곳에서 제공합니다.

## 실행 방법

```bash
cd naholo-beobe
npm install      # 최초 1회
npm run dev      # 개발 서버 → http://localhost:5173
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 로그인
데모 환경이라 **아무 아이디·비밀번호**로 로그인되며, 회원가입도 즉시 완료됩니다. (인증 상태는 localStorage에 저장)

## 기술 스택
- React 18 + Vite 5
- React Router 6 (공개 영역 / 로그인 후 `/app` 영역 분리, 라우팅 가드)
- Tailwind CSS v4 (Figma 디자인 토큰: brand `#64a8ff`, Pretendard 폰트)
- 외부 UI 라이브러리 없이 자체 컴포넌트 + 인라인 SVG 아이콘

## 화면 구성
| 영역 | 경로 | 설명 |
|------|------|------|
| 랜딩 | `/` | Hero · 서비스 소개 · 기능 · 이용 절차 · CTA · FAQ |
| 서비스 소개 | `/about` | 제안 배경 · 주요 내용 · 목표 · 기술적 당위성 · **변호사법 검토** |
| 로그인 | `/login` | 아이디/비밀번호, 비밀번호 보기, 아이디·비번 찾기 |
| 회원가입 | `/signup` | 실시간 유효성 검증(이메일·비밀번호 일치·약관) |
| 대시보드 | `/app/dashboard` | 진행 사건 요약 · AI 추천 작업 · 일정 · 활동 · 콘텐츠 |
| 판례 검색 | `/app/search` | 키워드/분류 검색, 판례 카드, 승소율·법령 분석 사이드 |
| 절차 안내 | `/app/procedure` | 단계 타임라인 + 서류 업로드/체크리스트/비용 계산기 모달 |
| 문서 생성 | `/app/documents` | 3단계 위저드(문서 선택 → 정보 입력 → AI 생성 결과) |
| 증빙 자료 | `/app/evidence` | 호증 번호 체계 · 상태 관리 · AI 보안/보완 점검 |
| 스케줄 관리 | `/app/schedule` | 인터랙티브 월 캘린더 + 기일통지서 자동 등록 모달 |
| 알림 관리 | `/app/notifications` | 알림 목록 · 알림 설정 토글 |
| 가이드 | `/app/guide` | 가이드·동영상·템플릿 |
| 마이페이지 | `/app/my` | 프로필 · 내 사건 · 계정 설정 (Figma 미설계분 신규 구현) |

## 원본 디자인 대비 반영/개선 사항
- 로그인 기본 버튼 라벨 정정: "회원가입" → **"로그인"**
- 회원가입 비밀번호 확인: 일치/불일치 **상태별 메시지** 분기
- 로그인에 **아이디 찾기 / 비밀번호 찾기** 진입점 추가
- Figma에 미설계였던 **마이페이지** 전체 화면 신규 구현
- 주신 제안 배경·법적 검토 내용을 **서비스 소개(/about)** 페이지로 반영
- 전 화면 하단/마이페이지에 **법률 자문 면책 고지** 명시
