# 예시 파일

화면을 시험할 때 쓰는 가짜 서류다. 실제 법원 서식과 문구를 따랐지만 **내용은 전부
지어낸 것**이고, 당사자·사건번호·금액은 앱의 데모 사건(`src/data/mock.js`)과 맞춰 두었다.

각 파일은 `.txt`와 `.pdf` 두 벌이다. 전자소송에서 실제로 내려받는 것은 PDF라서,
텍스트 레이어가 있는 PDF로 함께 구워 두었다. 파서가 PDF에서 글자를 뽑아내는 경로까지
그대로 시험할 수 있다.

## 법원통지서 — 일정 관리 › 법원 통지서 등록

| 파일 | 뽑히는 것 | 확인할 것 |
|---|---|---|
| `01-변론기일통지서` | 기일 2026. 8. 17. 14:00 · 제327호 법정 | 문서에 적힌 날짜를 그대로 읽는다 |
| `02-소장부본_답변서요구서` | 답변서 기한 = 송달일 + 30일 | 발송일(8/10)이 아니라 **송달일** 기준. 등재 후 미확인이면 8/17이 송달간주일 |
| `03-보정명령` | 보정서 기한 = 송달일 + 14일 | 기간을 문서 본문(`보정기한 14일`)에서 읽어 온다 |
| `04-변론준비기일_및_준비서면제출명령` | 기일 + 기한 **둘 다** | 한 장에 두 종류가 섞인 문서 |
| `05-이행권고결정` | 이의신청 기한 = 송달일 + 2주 | 불변기간. 지나면 확정판결과 같은 효력 |

서명란의 날짜(발송일)는 기일로 잡히지 않아야 한다 — 기일에는 반드시 시각이 붙는다.

## 숫자의 근거

- 지연손해금 연 12% — 「소송촉진 등에 관한 특례법」 제3조 제1항, 같은 항 본문의
  법정이율에 관한 규정(2019. 6. 1. 시행)
- 소 제기 전까지는 민법 정기이율 연 5%, 소장 부본 송달 다음 날부터 연 12%
- 인지액 — 민사소송등인지법 제2조 (1,000만원 → 50,000원 / 500만원 → 25,000원 /
  1,860만원 → 88,700원)
- 답변서 30일(민소법 §256①), 이의신청 2주(소액사건심판법 §5조의4①), 항소 2주(민소법 §396①)

## PDF를 다시 굽는 법

`.txt`를 고친 뒤 Chrome headless로 인쇄하면 된다.

```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
# txt → html(pre 태그로 감싸고 명조체 지정) → pdf
```

한글 폰트가 그대로 들어가야 `pdfjs`가 글자를 읽는다. 스캔 PDF(이미지만 있는 파일)는
글자가 없어 파서가 읽지 못하고, 앱은 "내용을 붙여 넣어 달라"고 안내한다.
